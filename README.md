
# 🏦 Bank.US — Приложение Личного Кабинета

Графическое приложение для генерации одноразовых кодов доступа и симуляции входа в банковский кабинет. Написано на **Python 3** с использованием библиотеки **PyQt6** и хранением данных в формате **JSON**.

## ✨ Особенности (Features)
* **Графический интерфейс (GUI):** Полностью переработано из консольной версии в оконное приложение Qt6.
* **База данных JSON:** Все данные пользователей и сгенерированные пароли автоматически сохраняются в файл `users.json` и не сбрасываются после перезапуска.
* **Безопасность:** Скрытый ввод паролей при авторизации.
* **Система логирования:** Встроенное в окно интерактивное поле логов, отображающее статус операций (зеленый/красный цвет в зависимости от успеха).
* **Защита от брутфорса:** Ограничение на 3 попытки ввода пароля с последующей блокировкой.

## 🛠️ Требования и установка

Для запуска проекта вам понадобится установленный Python версии 3.8 или выше, а также библиотека PyQt6.

### 1. Клонирование репозитория
```bash
git clone https://github.com
cd Bank
```

### 2. Установка зависимостей
Установите необходимый графический пакет:
```bash
pip install PyQt6
```

### 3. Запуск приложения
```bash
python bank_app.py
```

## 📂 Структура проекта
* `bank_app.py` — основной исполняемый файл приложения.
* `users.json` — локальный файл базы данных пользователей (создается автоматически при первом запуске).
* `.gitignore` — файл исключений для Git (игнорирует временный кэш Python и локальную базу `users.json`).
* `README.md` — документация проекта.

## ⚙️ Логика работы
1. При старте программа считывает `users.json`. Если файла нет, она автоматически подгружает дефолтный список пользователей (*Екатерина, Александр, Андрей, Викрам, Арнольда*).
2. Выберите имя из выпадающего списка.
3. Нажмите **"Сгенерировать пароль"** для создания уникального кода (формата `AA1234`). Код выдается один раз и сразу перезаписывает пустое поле в JSON.
4. Для проверки входа введите код в поле и нажмите **"Войти"**. У вас есть 3 попытки, после чего окно сбросит счетчик.
